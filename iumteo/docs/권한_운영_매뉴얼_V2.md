# 양양 이음터 V2.0 데이터 구조 및 권한 운영 매뉴얼

양양 이음터의 사용자 권한과 상태는 Firestore 문서 조합을 기준으로 결정되며, 관리자 대시보드에서 실시간으로 필터링하고 운영합니다. 모든 권한 설명은 본 문서의 기준을 우선으로 적용합니다.

## 1. 데이터 구조 및 권한 정의

### 1.1 사용자 등급(Role) 및 상태 플래그

#### 사용자 등급(Role)
| 등급 | 코드 | 핵심 권한 |
| --- | --- | --- |
| 비회원 | GUEST | 양양이음터 기본 기능과 강사 정보 조회만 가능 (연락처 열람 불가) |
| 일반 회원 | USER | 강사 상세 프로필 조회, 센터로 문의하기, 사용자 마이페이지 이용 |
| 강사 | INSTRUCTOR | 타 강사 상세 프로필 조회, 강사 마이페이지 이용, 본인 프로필 수정, 본인 사진 1장 관리 |
| 관리자 | ADMIN | 전체 운영 제어, 실시간 승인/필터링, 권한 스위칭 미리보기, 모든 개인정보 열람 가능 |

#### 상태 플래그(Status / Preview / Badge)
- **role**: 현재 세션에서 적용 중인 사용자 권한입니다.
- **actualRole**: 실제 계정 권한입니다. (미리보기 모드 전환 시에도 유지)
- **previewRole**: 관리자 권한 스위칭 툴바에서 선택한 미리보기 권한입니다.
- **isLocal (로컬 배지)**: `Y`일 경우 강사 카드에 초록색(`#2E7D32`) `[양양 로컬]` 배지를 노출합니다.
- **isSample (상태 배지)**:
  - `true`: 마이그레이션된 기존 데이터. 주황색 `[인증 대기]` 라벨 노출.
  - `false`: 신규 가입 후 관리자 승인 전. `[검토 중]` 라벨 노출.

### 1.2 권한별 접근 범위와 개인정보 경계 (안심 블라인드 정책)

양양 이음터는 강사의 개인정보 보호를 최우선으로 하며, 센터가 안전한 중개자 역할을 수행합니다.

| 구분 | 비회원 (GUEST) | 일반 회원 (USER) | 강사 (INSTRUCTOR) | 관리자 (ADMIN) |
| --- | --- | --- | --- | --- |
| 강사 목록/상세 프로필 조회 | 가능 | 가능 | 가능 | 가능 |
| 강사 개인정보(연락처, 이메일) | 불가 (블라인드) | 불가 (블라인드) | 불가 (블라인드) | 운영 목적 열람 가능 |
| 문의하기 | 불가 | 가능 (센터로 접수) | 불가 | 관리 전용 |
| 본인 프로필 수정 / 사진 관리 | 불가 | 불가 | 가능 | 가능 |
| 권한 스위칭 미리보기 | 불가 | 불가 | 불가 | 가능 |

### 1.3 회원가입 및 조건부 개인정보 동의 (Consent Gate)

최초 소셜 로그인 시, 가입 유형(일반/강사)에 따라 요구되는 개인정보 동의 항목이 동적으로 변경(조건부 렌더링)됩니다.

**일반 회원 가입 시:**
- `[필수]` 서비스 이용 및 개인정보 수집·이용 동의
- `[선택]` 홍보 및 마케팅 정보 수신 동의

**강사 회원 가입 시:**
- `[필수]` 서비스 이용 및 개인정보 수집·이용 동의
- `[필수]` 개인정보의 제3자 제공 및 프로필 대외 공개 확약 (※ 연락처는 블라인드 처리되며 매칭 문의는 센터를 통해서만 진행됨을 명시)
- `[선택]` 홍보 및 마케팅 정보 수신 동의

**데이터 처리:**
- 동의 내역은 타임스탬프와 함께 Firestore Users 컬렉션의 `consent_log`에 기록됩니다.

## 2. 사용자별 운영 흐름

- **비회원**: 기본 정보 조회 가능. 로그인 진입점 노출.
- **일반 회원**: 로그인 후 USER 세션. 마이페이지에서 문의 현황 확인.
- **강사**: 로그인 후 INSTRUCTOR 세션. 본인 프로필 관리.
- **관리자**: 대시보드에서 데이터 실시간 필터링(`onSnapshot` 활용) 및 권한 스위칭.
