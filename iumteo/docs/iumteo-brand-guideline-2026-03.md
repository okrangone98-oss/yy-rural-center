# 양양 이음터 브랜드 가이드라인

## 1. 서비스 정의

양양 이음터는 양양군 농촌활성화지원센터가 운영하는 비영리 지역 커뮤니티 플랫폼입니다.
강사님, 기관, 지역 주민, 일반 이용자가 서로 연결되고 문의와 채팅을 통해 수업 문의, 업무 협의, 지역 협업이 이어지도록 돕습니다.

이음터는 상업형 매칭 플랫폼이 아니라 지역 관계를 연결하고 성장시키는 운영형 서비스입니다.

## 2. 핵심 대상

- 강사님: 교육, 체험, 프로그램, 지역 서비스를 운영하는 지역 강사와 활동가
- 기관: 센터, 학교, 마을 조직, 공공기관, 주민 모임 등 협업 주체
- 지역 주민: 강사님을 찾고 문의하는 일반 회원
- 운영자: 문의 흐름, 공지, 데이터, 안내를 관리하는 센터 담당자

## 3. 브랜드 원칙

- 지역성과 공공성을 먼저 드러냅니다.
- 거래나 수익보다 연결, 협의, 신뢰, 관계 성장을 강조합니다.
- 강사님과 일반 이용자를 동일한 공동체 구성원으로 존중합니다.
- 센터는 중간에서 안전하게 연결하고 안내하는 조력자 역할을 맡습니다.

## 4. 용어 기준

이음터에서는 상업 플랫폼식 표현을 그대로 쓰지 않습니다.

| 사용 지양 | 이음터 권장 표현 |
| --- | --- |
| 고수 | 강사님 / 지역 강사 |
| 고객 | 기관 / 지역 주민 / 일반 이용자 |
| 견적 | 문의 |
| 견적 요청 | 문의하기 중 |
| 받은 견적 | 받은 문의 |
| 서비스 | 교육 / 서비스 / 프로그램 / 협의 |
| 고수찾기 | 강사찾기 |
| 커뮤니티 | 공지사항 / 센터 소식 / 지역 안내 |

### 문장 원칙

- 강사 화면에서는 `강사님` 호칭을 우선 사용합니다.
- 회원 화면에서는 `기관`, `지역 주민`, `일반 이용자` 맥락을 자연스럽게 구분합니다.
- `문의`, `채팅`, `협의`, `진행`, `관계 성장` 같은 표현을 우선 사용합니다.
- `견적`, `거래`, `수익`, `고객 확보` 같은 상업형 문구는 기본적으로 사용하지 않습니다.

## 5. 핵심 메시지

### 메인 메시지

- 강사님과 기관, 지역 주민을 연결합니다.
- 문의가 수락되면 채팅으로 협의를 이어갑니다.
- 서비스 진행 후 양양 지역과 함께 관계가 한층 더 성장하였습니다.

### 강사님용 메시지

1. 기관과 지역 주민의 문의를 받습니다.
2. 원하는 문의를 확인하고 채팅으로 협의합니다.
3. 서비스 진행 후 양양 지역과 함께 관계가 한층 더 성장하였습니다.

### 피해야 할 문구

- 첫 고객부터 첫 수익까지
- 견적 보내기
- 거래 완료
- 고객 확보

## 6. 화면 구조 원칙

### 비회원 메인

- 강사찾기
- 공지사항
- 로그인 / 회원가입
- 이음터 소개
- 문의와 채팅 흐름 안내

### 일반회원 화면

- 문의하기 중
- 채팅 진행
- 문의 완료
- 새 알림 요약
- 강사찾기와 공지사항 진입

### 강사님 화면

- 받은 문의
- 채팅 진행
- 문의 완료
- 새 알림
- 강사 카드 관리

## 7. 디자인 원칙

- 메인 톤은 현재의 녹색 계열을 유지합니다.
- 숨고 같은 서비스에서는 정보 구조만 참고하고, 언어와 목적은 이음터 기준으로 다시 씁니다.
- 카드는 단순하고 명확하게, 상태 구분은 배지와 요약 카드로 보여줍니다.
- 화려한 상업 광고 톤보다 신뢰감 있는 지역 공공 서비스 톤을 유지합니다.

## 8. MVP 우선순위

1. 메인과 로그인 흐름이 자연스럽게 연결될 것
2. 강사찾기, 공지사항, 문의, 채팅이 끊기지 않을 것
3. 강사님이 받은 문의와 채팅 상태를 한눈에 볼 수 있을 것
4. 일반회원이 문의 진행 상태를 쉽게 이해할 수 있을 것
5. 화면 전반의 용어가 위 기준과 일치할 것

## 9. 체크리스트

- `고수`, `고객`, `견적` 문구가 남아 있지 않은가
- 강사님 화면에서 `받은 문의`와 `채팅`이 자연스럽게 보이는가
- 일반회원 화면에서 `문의하기 중`과 `받은 문의` 흐름이 직관적인가
- 공지사항이 센터 소식과 지역 안내 역할을 하고 있는가
- 서비스 소개가 비영리 지역 커뮤니티 플랫폼 맥락을 유지하는가
